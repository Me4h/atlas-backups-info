ATLAS Backups

ATLAS Backups is an administrator-operated tool being configured to store and restore encrypted backups of the ATLAS application using the administrator’s Google Drive account.

Purpose of Google Drive access

Google Drive authorization allows the backup tool to create, list, read and manage backup files in the account authorized by the administrator. Backup retention may involve deleting older backup files.

This integration is for the operator’s own backup administration. ATLAS customers do not need to connect their Google accounts to this tool.

About this website

This public website provides information about the backup integration and its privacy policy. It does not provide access to backup files or an account sign-in form.
