Privacy policy

This policy covers the ATLAS Backups Google Drive integration and this informational website. It does not replace the privacy policy for the ATLAS customer application.

Operator and purpose

The ATLAS administrator operates ATLAS Backups for administration, storage and restoration of ATLAS backups. The integration is intended for use with the operator’s authorized Google Drive account.

Google data and authorization

The backup tool uses OAuth authorization tokens and accesses file contents and metadata, such as file names, identifiers, sizes and modification times, as needed to manage backups. Depending on the permissions granted, Google Drive access may be broader than the backup folder; the intended use is limited to backup operations.

Use and storage

Google Drive data is used only to upload, locate, verify, restore and manage backup files. It is not used for advertising, sold, or used to train artificial intelligence models. The backup workflow is designed to encrypt backup contents before uploading them. Authorization tokens and encryption credentials must be kept in the operator’s private environment, separate from this public website.

Service providers and sharing

Google Drive stores the uploaded backup files. The server hosting the backup tool processes backup operations. This informational website is hosted by GitHub Pages. Its hosting provider may process technical request information, such as IP addresses, to deliver and secure the website. This website adds no analytics, tracking scripts or contact forms.

Retention and deletion

Backup files are retained according to the retention settings configured by the operator, until removed by the backup process or manually. No retention schedule is established by this website. Deleting this website or revoking authorization does not delete files already stored in Google Drive.

Revoking access

The account holder can revoke the integration’s access in their Google Account connections settings. Backup files can be deleted separately from Google Drive, including its trash. The operator can also remove locally stored authorization credentials.

Contact

For general questions about this integration, use ATLAS Backups support. Do not include backup contents, personal data, passwords or authorization tokens in public support requests. The authorized account holder can manage access and delete backup files directly as described above.
